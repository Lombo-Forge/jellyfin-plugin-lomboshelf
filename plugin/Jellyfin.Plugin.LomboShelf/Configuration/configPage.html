Theme

Features

Home shelf rows

Collection rows

One per line: collection name, then optionally a row title and a number of items (1-50), separated by |. For example: Leaving soon | Leaving soon | 20. The name must match the collection exactly. At most 5 rows. Leave empty for none (the default).

Storage tags (optional, off by default)

Shows an SSD or HDD badge on a title's page, read from the tiers.json file that LomboTier writes. The server looks the folder up; the browser never sees a path. The shared file formats are described in the Lombo hub repository's docs/contracts.md.

Removed from the start of a title's file path in Jellyfin, so what is left matches the "path" in tiers.json.

Keep button (optional, off by default)

Shows "Leaving in N days" and a "Keep it longer" button for titles listed in the leaving.json file that LomboFarewell writes. Pressing the button makes this server call Farewell; the token below is kept on the server and is never sent to a browser.

Needed only when LomboFarewell limits keeps per person. Turn on only with LomboFarewell 0.3.0 or newer; older versions refuse the extra key. The name is the signed-in person's own, read by this server, never taken from the browser.

Travel button (optional, off by default)

Shows a small "Travelling?" card on Home where a signed-in person can allow sign-in from abroad for themselves, through LomboVisa's self-service API. This server makes the call for the signed-in person only; the token below is kept on the server and is never sent to a browser.

Other

For example: [{"label": "Anime", "items": [["Anime", "Shows"], ["Anime Movies", "Movies"]]}]. Each item is a library name and its type (Movies or Shows). Leave as [] for none.
